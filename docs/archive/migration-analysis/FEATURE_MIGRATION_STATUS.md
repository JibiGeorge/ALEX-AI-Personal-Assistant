# Feature Migration Status

Updated: 2026-11-01

## Status definitions

- **Complete:** implementation and behavior-focused tests demonstrate parity for the documented scope.
- **In progress:** functional code exists but parity, edge cases or platform validation remain.
- **Not started:** no migrated behavior is exposed.
- **Source missing:** README documents the capability, but its implementation is absent from the supplied source checkout.

## Acceptance evidence

Before calling the migration complete:

1. Each implementation-backed source feature has a row marked Complete with linked tests and known platform coverage.
2. All high-risk side effects (file writes/deletes, messages, power/network, code execution) have explicit policy tests.
3. Desktop/backend integration tests verify spawn, readiness, auth, failure reporting and shutdown.
4. Regression checks compare observable behavior and errors with the original where the original is executable.
5. Source-missing README claims are resolved with original source or explicitly excluded by user approval; they are never represented by placeholder controls.
